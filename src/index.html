Sistema de Inventario para una Distribuidora

Bienvenido a nuestro sistema de inventario

Este proyecto tiene como finalidad mejorar el control y la administración de los productos de una distribuidora.

Mediante este sistema se busca organizar las entradas y salidas de mercancía, consultar las existencias disponibles y reducir las pérdidas de inventario.
